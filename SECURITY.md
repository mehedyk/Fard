# Security Policy

Fard generates passwords entirely in your browser. It has no server, no analytics and makes no network requests of its own.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

- Use GitHub's private "Report a vulnerability" option on the repository's Security tab, or
- Email kawser2305341202@diu.edu.bd with reproduction steps.

Please allow reasonable time for a fix before public disclosure.

## What's in scope

- Anything that makes generated passwords predictable or biased
- Anything that sends passwords or inputs off the device
- Flaws in the entropy estimate that overstate strength
